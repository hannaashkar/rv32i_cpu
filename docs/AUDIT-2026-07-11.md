# Full-project audit — 2026-07-11

Method: 8-dimension multi-agent audit (RTL area, timing, Quartus settings,
build system, verification, software, docs, hygiene); every medium/high
finding adversarially verified against the actual files/reports by an
independent checker before inclusion. 65 raw findings → **36 confirmed**,
2 refuted (both were already-documented deliberate calls), 27 minor.

Evidence base: the FAILED D023 fit (`synth/output_files/rv32i_cpu.fit.rpt`,
routing congestion at 96% LEs, A&S 53,200 LEs) — first time the per-entity
resource table was actually read.

Legend: **[H]**anna decision (microarchitecture) / **[C]**laude
(infrastructure). Status boxes updated as items land.

## 1. Strategy-changing discoveries (area)

The per-entity fitter table rewrites the shrink plan — there are TWO LE pigs,
not one, and together they are ~44% of the 10M50:

| Entity | Fitted LCs | Regs | Root cause |
|---|---|---|---|
| `gshare_bp:BP0` | **11,137** (fit.rpt:1440) | 5,926 | PHT-side read/update networks; PHT duplicated per read port |
| `ooo_prf:PRF0` | **10,947** (fit.rpt:1507) | 2,048 | 64×32 flop array, 6 async read ports (`rd_bypass`, ooo_prf.v:35-51), 3 write ports |
| `ooo_iq:IQ0` | 8,378 (fit.rpt:1505) | 2,720 | 162-bit uop payload muxed 16:1 on 3 select ports |
| flat `ooo_cpu` | 14,132 | — | incl. ~3k LEs of RAT checkpoints (8×192b + dual rat_after0/1 snapshot networks, ooo_cpu.v:438,601-611) |

- [ ] **[H] gshare shrink — CORRECTED AIM.** The BTB data arrays are
  **already M9K** in this build (btb_target/btb_tag/btb_cond each show
  0 LCs — Quartus auto-mapped altsyncram). The 11,137 LCs are PHT-side.
  Design options must target the PHT read/update path — not the BTB.
  **DONE 2026-07-12 (D024, branch `gshare-m9k-pht`): Hanna picked A1;
  even/odd banked M9K PHT shipped. A&S 53,200 → 46,620 LEs (−6,580,
  12.4% of the device), registers 18,976 → 16,995, PHT in 2 M9Ks.
  CoreMark IPC 1.026 KEPT (official CRCs, 432.8M instructions lockstep-
  clean); OoO 19/19+40/40+25/25+25/25-vio. INV-G1 + INV-G2 self-checks
  armed. Board fit re-run to unblock the D023 demo.** See DECISIONS.md
  D024 / docs/GSHARE_SHRINK.md.
- [ ] **[H] PRF → M9K via LVT replication.** Est. ~9-10k LEs freed for
  ~18 M9Ks (M9K usage is only 41%). IPC-neutral by the same read-latch
  fold argument as D016/D022 (read addresses already registered:
  `rf_u` at ooo_cpu.v:688-690). Options sheet before RTL.
- [ ] **[H] IQ payload split** (wakeup array vs payload RAM). 111 of the
  162 uop bits (U_IMM/U_PC/U_PNPC/U_GHR/U_RS1A) are never consulted by
  scheduling logic — classic payload-RAM split. Est. ~3k LEs; also
  de-risks the future 2-stage scheduler (less state to pipeline).
- [ ] **[H] Checkpoint slimming**: NCHKPT=4 (A/B the dispatch-stall cost),
  or M9K checkpoint file (+1 mispredict cycle), or drop the second
  same-cycle checkpoint port (delete rat_after1 network). ~1-3k LEs.
- [ ] **[C] Async resets on pure payload arrays** (IQ `u[]`, ex_a/ex_b,
  wb_val, dr_* payload, SQ addr/data, rob_pc — ooo_iq.v:270-276,
  ooo_cpu.v:1167-1193, ooo_sq.v:157-164) block RAM extraction and bloat
  the reset net. Valid-bit reset alone is architecturally sufficient.
  Mechanical, lockstep-verifiable, one module per commit — but Hanna
  ACKs the list first (X-semantics change in 4-state sims).

Combined realistic ceiling: board top from ~48k to low-30k LEs → routing
slack for the parked D023 demo AND the 2-stage scheduler.

## 2. Timing truths

- [ ] **[C] D022's 18.64 MHz was an Auto-Fit FLOOR** — fit_d022.log
  contains "Optimizations ... were skipped" ×4. Re-run one STANDARD FIT
  + STA before any PLL-ratio decision.
- [ ] **[H] JALR target adder.** The JALR target/mispredict compare rides
  the full ALU result mux incl. the barrel-shifter cone (~10 ns on the
  dmem-load→bypass→JALR→BTB critical path). A dedicated rs1+imm adder
  cuts it. Small RTL change, lockstep-verifiable.
- [ ] **[H] Clock plan: /2 = 25 MHz is NOT reachable** on the current
  netlist (needs ~-13.7 ns). Honest post-shrink step = fractional PLL
  20-22 MHz (Fmax/~1.15 margin policy = Hanna's call); 25 MHz plausible
  only with gshare shrink + JALR adder + routing relief.
- [x] **[C] No fit/STA make target, no critical-path archiving** → added
  (`make synth-fit` / `synth-sta`, see Makefile).

- [x] **[C] Coverage collection is entirely missing** — DONE 2026-07-11,
  re-measured 2026-07-14: `make coverage` (line-coverage builds of both
  cores, 60 programs each, verilator_coverage merge) — **99.2% RTL line
  coverage (1428/1440)**, published in docs/VERIFICATION.md. Still open as a
  follow-up: ifdef'd functional cover points (IQ full, SQ full,
  checkpoint-starve, LQ violation, RAS overflow...).
- [x] **[C] FENCE/ECALL/EBREAK/reserved opcodes never executed by any
  test** — DONE 2026-07-14. Directed `sys_nops.S` proves sequential/exact
  retirement and no register/CSR/memory side effects. Additive `--sys`
  random lane: 25/25 seeds on each core, 1,148 injected words per core,
  zero lockstep divergence; established default and `--vio` seed hashes
  stayed byte-identical. Both decode/control modules are now line-covered.
- [ ] **[H picks invariants / C encodes] Zero assertions in the highest-
  risk modules**: ooo_lq.v, ooo_sq.v, ooo_prf.v, ooo_decode.v,
  gshare_bp.v (B013/B014 both lived exactly here). Candidates: freelist
  popcount + in-flight == 64; RAT==aRAT when ROB empty; SQ drains in age
  order; no LQ entry survives flush; no two LQ entries share a tag.
- [x] **[C] Divergence diagnostics are single-point** — DONE 2026-07-11:
  64-entry retired-instruction ring buffer + full ISS register dump on
  every mismatch path, `+trace_at=<cycle>` late-opened FST, and a
  permanent `+force_diverge=<n>` self-test (verified firing on both
  cores, exit 3 with full context).
- [ ] **[C] Random generator blind spots**: forward-only control flow (no
  loops, no call/return trees, no RAS-depth stress, JALR always +12).
  **NPU sub-gap DONE 2026-07-14:** additive `--npu` mode targets the
  B010/B011 ordering space with 282 adversarial bursts / 564 GO commands
  per core across 25/25 lockstep-clean seeds; golden default/`--vio`
  streams stayed byte-identical. Remaining: loop/call-tree/RAS modes.
- [x] **[C] Reset/X-state never randomized** — DONE 2026-07-14. Separate
  in-order/OoO models use `--x-assign unique --x-initial unique`; the full
  directed+C suite runs at four explicit `+verilator+rand+reset+2` seeds.
  Both cores passed 80/80 program-seed runs, lockstep-clean. The lane is a

- [ ] **[C] SIM_BIG_MEM means the synthesized memory geometry (board-
